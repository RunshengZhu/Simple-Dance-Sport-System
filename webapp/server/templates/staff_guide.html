{{ '检录快速流程' if guide_role == 'marshal' else '主持快速流程' }} 照着做，四步一场

本页可直接打印；角色切换见页尾链接。芯片显示背号 + 姓名，红色高亮 = 正在评分的场次。

1 打开工作台

用管理员发的账号口令登录本赛事（直达链接也可）。按场序列出场次卡： 「待开始」等开赛、「评分中」红框高亮、「已发布」可看成绩。

{% if guide_role == 'marshal' %}

2 检录：点芯片，绿=到场

对照上场名单点芯片（背号 + 姓名），变绿即到场，再点取消；整队到齐点「全部检录」。 卡头实时显示「检录 N / M」。未检录的背号在裁判评分页灰显 🔒——检录完裁判立即可评。

{% else %}

2 开赛：检录完成后点「开赛」

主持人可对「待开始」场次直接点「开赛」开启本场评分（无需找管理员）—— 裁判工作台立即出现该场。开赛后如需关闭/重开，联系赛事管理员。

{% endif %}

3 成绩出来后原位查看

已完成的场次卡片内点「查看成绩 ▾」——名次 / 背番号 / 选手姓名 / 总分 / 晋级（决赛为「录取」）一列标清 ✓，原地展开不跳页；宣读或核对后点「标记已播报」打勾备忘。

4 场次多时快速定位

用顶部「待检录 / 已完成」筛选 + 编号搜索；点「场次索引」按分组跳转； 卡片左上的红色场序章就是全场统一的出场序号。

遇到这些情况

显示「前置轮次未完成」晋级轮名单未生成——上一轮晋级确认回填后自动出现
检录错了再点一下芯片取消即可；批量用「全清」
成绩要撤回重算联系赛事管理员在总表「退回评分」
