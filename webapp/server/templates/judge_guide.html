裁判快速上手 到场 3 步开始打分

本页可直接打印随身携带；完整说明见 使用手册。评分全程只看背号不见姓名，请独立评判。

第 1 步 · 打开你的评分入口

赛前领取专属二维码或直达链接（每名裁判不同，形如 /login?role=judge&judge=J1）。 手机扫码或点链接即自动进入本赛事工作台——无需账号口令。建议扫码后把页面添加到手机主屏/书签，整场比赛随时打开。

第 2 步 · 一键进入正在评分的场次

工作台顶部有红色「● 正在评分 · 快速进入」横幅——主持人开赛后这里会立即出现当前场次的按钮， 点按钮直达该场你还没打完的舞种，不用自己找。也可以在下方场次列表里点舞种进入。

评分页顶部有「← 上一场 / 下一场 →」导航和「● 正在评分」按钮，随时切换场次。

第 3 步 · 按制式打分并提交

制式怎么打提交条件
Mark 制
预赛晋级票		 点选手行给 Mark（再点取消）。打开默认全空，可用「全选 / 清空」快捷按钮；通常勾选人数 = 晋级名额 勾选数达到晋级名额后提交键才可用（不足时置灰并提示还差几人）
顺位法
决赛排名		 给本场全部选手排名次（1=最好，不并列）。两种方式：顺序点选按名次依次点选手；直接指定先点选手再点下方名次键盘。点已排选手取消并自动补位 全部已检录选手都排出名次
评分制
集体舞		 每位选手给 0~10 分（一位小数），点输入框唤起数字键盘 全部选手都有分数

底部提交按钮常驻不随滚动消失。提交后如场次未关闭可修改重交；最后一名裁判提交完，名次自动产生。 评分过程中页面自动暂存——锁屏 / 误刷新 / 断网后重新打开会恢复，提交成功才清空。

常见问题

情况说明
背号灰显 🔒该选手未检录，不可评分；等检录台确认后自动恢复（页面实时同步）
工作台没有场次场次尚未「开赛」——主持人/管理员开赛后立即出现，稍等刷新即可
提示「已被禁用评分」管理员在总表「裁判启用」栏把你暂时停用了；本场只读，联系管理员恢复
提交键灰色Mark 制未勾满晋级名额 / 顺位法还有人没排名 / 评分制有人没打分——补齐即可提交
「还差 N 人满足名额」Mark 制的提交门禁提示：继续勾选到名额数即可
打分页右上「? 评分说明」随时点开查看当前制式的打分要点
