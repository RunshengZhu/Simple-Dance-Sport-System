赛事评分系统 · 使用说明

面向体育舞蹈赛事的评分与流程工具。按角色查找你的操作即可；每一步都配实机标注图。

培训材料下载（幻灯片版，按角色 × 赛事全生命周期）

培训幻灯片（PDF · 16:9 · 21 页）—— 截图为主的讲解版：全生命周期泳道总览，管理员/检录/主持/裁判四章覆盖各自从筹备到收官的完整动线， 附观众与大屏、异常处置速查表；适合培训会投屏或打印成讲义。

三步办好一场赛事（新赛事筹备向导）

创建赛事、导入名单、排赛程、建工作人员账号，全部在一个向导里完成。

第 1 步 · 总管理员：建赛并发账号

赛事管理页填写名称 / 日期 / 地点，展开「同时创建赛事管理员账号」填用户名口令，一次提交（自动激活）。

① 名称 / 日期 / 地点　② 赛事管理员账号、口令　③ 创建（自动激活）

① 反馈：已激活、管理员账号就绪　② 列表显示「激活中」

如有需要，在「用户」页补建检录 / 主持账号：角色选对应项；赛事管理员须绑定赛事 ID。

① 角色选「赛事管理员」　② 绑定赛事 ID　③ 账号信息　④ 创建账号

最后把专属登录入口 /competitions/赛事ID/login 和账号发给组织者。

第 2 步 · 赛事管理员：五步筹备向导

组织者打开专属登录入口（角色已预选「赛事管理员」），填账号口令登录——登录后浏览器即绑定本赛事，自动进入筹备向导。

① 角色已预选　② 账号、口令　③ 登录本赛事

向导 ① 确认赛事信息——总管理员已填，核对即可，点「下一步」。

向导 ② 导入选手——下载模板 → 按列填好 → 上传；页面即时反馈导入结果与当前总人数。

向导 ③ 导入裁判——同上；建议 5 或 7 名（顺位法按多数票计算）。

向导 ④ 导入赛程——每行一个场次：编号、名称、舞种、评分制式、晋级名额与参赛选手；上传后即成赛程树。

向导 ⑤ 创建工作人员账号——为检录台和主持台各建至少一个账号，创建后立即分发。

向导 ⑥ 完成摘要——核对选手/裁判/场次/账号总数；点「开场第一场」可直达控制台开赛， 或「完成向导」进入赛程编排页。

CSV 速查——选手：背番号,项目编号,姓名,学校/单位（一人多项目填多行，集体舞用 T 编号）； 裁判：裁判ID,姓名；赛程：场次编号,场次名称,项目编号,轮次,舞种,评分类型,晋级人数,参赛选手 （评分类型填 SKATING/MARK/SCORE；预赛填晋级人数，决赛填 0 且参赛选手可留空）。

第 3 步 · 比赛日

控制台「开启评分（按已勾选上场名单）」→ 检录台点名 → 裁判评分 → 收齐自动算分 → 结果中心发布（可开「自动发布」）→ 主持台播报。 详细操作见下方各角色章节。

多场赛事并行

多场赛事可同时激活、数据独立；公开页/检录台/裁判台展示最新激活的一场。各赛事由自己的赛事管理员管理，互不干扰。

一、赛事管理员：赛事日常管理

数据与名单调整

筹备向导覆盖首次导入；之后的增补修改走两个入口：导入页重传整份 CSV（传错逐行提示，可反复重传）， 或赛程编排页直接添加/修改/删除未开始场次。已开始评分的场次修改名单会清空评分，请谨慎。

控制台：每场比赛的操作台

状态行常驻「开启评分（按已勾选上场名单）」——名单来自导入/晋级回填，默认已勾选，一键开场。 开场后页首常驻裁判提交进度矩阵；随时「关闭评分」或「退回评分」。

结果中心：发布与晋级

收齐自动算分；「发布」即上大屏与观众页，可撤回。预赛发布后会出现「下一流程：晋级确认」引导条， 点击生成预案、勾选晋级者确认，名单自动蛇形回填到下一轮。

团体总分与大屏控制

「团体总分」页核对单位积分（口径可选，仅计已发布场次）；「大屏控制」页可锁定现场大屏画面或恢复自动轮播。

数据安全

所有评分改动都有追加式历史（旧值→新值+操作人）；退回评分/撤销检录等敏感操作全部记入「用户」页审计日志。 支持全量导出（JSON/SQLite）与原子恢复；部署层每日自动备份见 docs/DEPLOY.md。

二、评分基础：三种评分制

顺位法（Skating，SKATING）——标准舞/拉丁舞决赛标准用法。 每位裁判独立给本场全部选手排名次（1=最好，不并列），不打分、只排名。 全部裁判交卷后按 Skating 规则汇总：从第 1 名开始逐席检查，谁先被「过半数裁判」排进名次内谁先得席， 平票时比较名次之和。多数票机制让单 位裁判无法操纵结果。
Mark 制（MARK）——预赛淘汰专用。裁判不排名次，只勾选应当晋级的选手 （通常勾选人数 = 晋级名额）；被过半裁判勾选的选手晋级下一轮。只分「晋级 / 淘汰」，最快速。
评分制（SCORE）——集体舞等场合使用。每位裁判按表现给 0~10 分（一位小数）， 系统汇总全部裁判的分数排出名次。适合需要区分优劣程度的场合。

三种制式在赛程里按场次指定，裁判端会自动呈现对应的评分界面，无需裁判自己选择。

三、检录：确认到场

逐个背号确认到场

检录台按场次列出背号芯片：点一下变绿 = 到场，再点取消；人多用「全部检录」。 顶部实时显示「检录 N / M」；可用筛选和编号搜索定位场次，场次很多时点「场次索引」按分组跳转。

裁判端同步：未检录背号在评分页灰显「🔒 未检录」。

四、主持人：播报

查看成绩公告并播报

已算完的场次出现在「已完成场次」区，点「查看成绩 ▾」原位展开公告（名次/背番号/选手队伍/总分）， 宣读后点「标记已播报」打勾备忘。需要纸质稿点「下载本场成绩单」。

五、裁判：三步完成评分

公平性约定：只见背号不见姓名；只有已检录的背号可评（未到场灰显 🔒）。 打分过程中页面自动暂存——锁屏/误刷新/断网后重新打开会恢复，提交成功才清空。

第 1 步 · 打开专属链接

赛前领取直达链接（形如 /login?role=judge&judge=J1），打开即自动定位到本赛事，建议存为书签。

第 2 步 · 从工作台进场次

工作台列出所有进行中场次与舞种入口，页首实时显示「待评 N / M」。

第 3 步 · 按制式打分并提交

顺位法——两种习惯任选：顺序点选按名次依次点选手；直接指定先点选手再点下方名次键盘。

Mark 制——点击选手行给予 Mark（通常为晋级名额数），再点取消，页顶实时显示已选人数。

评分制——点输入框给 0~10 分。

提交后场次未关闭可修改重交；最后一名裁判提交完，名次自动产生（开「自动发布」则直接上大屏）。

六、观众：随时查询

看赛程、查成绩、找选手

公开赛程看每场状态；公开成绩看已发布名次（含选手与队伍）；「按背番号查询」输入背号即查； 团体总分实时更新（仅计已发布场次）。

七、大屏：挂机展示

现场大屏

自动轮播：欢迎页 → 评分进行中 → 成绩公告（逐场）→ 团体总分榜；有内容才轮播。 管理员可强制锁定某一画面，变更即时推送。按 1080p 设计，无滚动条。

文件分发与数据安全

「文件」页提供分层托管（public/token/admin 三档权限），上传后复制链接即可分发成绩册、规程等材料。 数据安全：评分全程留痕、敏感操作审计、全量导出/原子恢复、每日自动备份（见 docs/DEPLOY.md）。
