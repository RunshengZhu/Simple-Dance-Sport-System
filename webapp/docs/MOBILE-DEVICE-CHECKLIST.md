# 移动真机验证清单（MOBILE-DEVICE-CHECKLIST）

> 背景：现有自动化测试全部基于桌面 Chromium（Playwright 模拟），iOS Safari / Android Chrome 真机行为从未实测。
> 本清单覆盖代码审查确认的高风险域：SSE 断连重连、软键盘遮挡、Service Worker、深浅主题、滚动点按、大屏轮播。
> 测试环境：`http://59.110.90.21:8321`（HTTP+IP 直连，与 LOADTEST-R41 基线一致）。
> 用法：每台设备打印一份，逐项勾选；任何一项不符即按第五节格式记录问题。

**前置准备（两端通用）**
- [ ] 测试账号可用：裁判账号（评分页）、检录长账号（检录台）；公开页与 /screen 无需登录
- [ ] 数据就绪：至少 1 场「评分中」场次、1 场已完成场次（公开页有锚点条与成绩卡）、检录台 6 场以上场次卡

- [ ] 记录系统深色模式当前值（主题项需在系统设置中来回切换）

## 二、iPhone / iPad Safari 验证清单

### 2.1 SSE 断连与重连（入口：`/staff` 检录台、`/judge`→任意场次评分页、`/screen`；页头右侧连接圆点 ●）
- [ ] SSE-1 锁屏断连：打开检录台待圆点常亮 → 锁屏 30 秒以上 → 解锁回页面。预期：圆点先变灰（断连自动转轮询兜底），数秒内恢复常亮；后台期间他人检录变化已补刷到列表
- [ ] SSE-2 网络切换：保持页面打开，关 Wi-Fi 切蜂窝，再切回。预期：圆点变灰→恢复；恢复后点任意背号芯片可正常检录，无状态错乱
- [ ] SSE-3 评分页联动：A、B 两设备同开一场评分页，A 检录/撤销一名选手，B 不刷新应看到该背号自动置灰/恢复，且 B 正在输入的分值不被清空、页面不整体重载
- [ ] SSE-4 飞行模式极端：开飞行模式 60 秒 → 关闭。预期：无报错弹层，圆点自动恢复，全程无需手动刷新
- [ ] SSE-5 大屏重连快照：`/screen` 断连恢复后，评分中/成绩/总分三节内容与当前实际一致

### 2.2 软键盘（入口：评分页评分制场次 `inputmode=decimal` 输入框；`/staff` 搜索框；`/public/results` 背番号查询）
- [ ] KB-1 键盘遮挡：点列表最后一个选手的分值框唤起数字键盘。预期：该行滚到键盘上方可见；吸底「提交」栏在键盘收起后回到页面底部，未被顶飞或永久遮挡
- [ ] KB-2 输入体验：键盘为数字+小数点布局（无字母行）；能输入 7.5 一位小数；无自动大写/纠错干扰
- [ ] KB-3 检录台搜索：聚焦搜索框时页面不异常跳顶，键盘弹起后搜索框与场次卡仍可见；输入关键词（或回车）后首个匹配场次平滑滚入视口并红色高亮约 1.7 秒
- [ ] KB-4 收起残影：评分页收起键盘后页面可正常滚动到底，底部无空白条残留（iOS 常见键盘收起 bug）
- [ ] KB-5 公开页查询：`/public/results` 点查询框唤起数字键盘，输入背番号点「查询」结果正常显示

### 2.3 PWA / Service Worker（入口：`/apps/wuzhen/`）
注意：当前为 HTTP+IP 部署，Service Worker 仅在 HTTPS（或 localhost）下可注册，注册失败属预期而非缺陷——如实记录实际表现即可。
- [ ] SW-1 首次打开 `/apps/wuzhen/`：页面正常渲染无白屏；分享菜单「添加到主屏幕」可用
- [ ] SW-2 记录 SW 注册实际结果：预期 HTTP 下注册失败/无 SW；页面功能是否全部可用，console 提示原文照抄进问题记录
- [ ] SW-3 断网重开：正常加载一次 → 开飞行模式 → 重开同 URL。预期：普通页面不可用（无缓存兜底）属预期；从主屏幕图标打开的表现另记录
- [ ] SW-4 主屏幕图标打开：布局不被 Safari 工具栏遮挡，横竖屏正常

### 2.4 深浅主题切换（入口：任意页页头主题切换按钮；存储键 `ds-theme`）
- [ ] TH-1 手动切换持久：切深色 → 锁屏再解锁 → 仍深色；杀掉 Safari 重开仍是深色
- [ ] TH-2 切后台回前台：切深色 → 回主屏再回 Safari → 主题保持，无白屏闪烁
- [ ] TH-3 跟随系统：清除站点数据后首次访问（未手动选过主题）→ 系统设置切深色 → 回前台页面自动变深色；切回浅色同理（手动选过则不跟随，属预期）
- [ ] TH-4 状态栏配色：深色下 Safari 顶部区域为深色（meta theme-color 同步），浅色为米白
- [ ] TH-5 深色下聚焦输入框：键盘弹起前后页面无白色色块闪现

### 2.5 滚动与点按（入口：`/staff`、`/public/results`）
- [ ] SR-1 长列表流畅：检录台 6+ 场次卡（含 48 人芯片组）上下滚动流畅，无卡顿白屏
- [ ] SR-2 背号芯片：连续快速点击相邻两个背号，各自状态独立切换正确；按压有缩放反馈；误触相邻芯片的情况记 0 次
- [ ] SR-3 成绩手风琴：点「查看成绩 ▾」平滑展开、再点收起无跳动；一次只展开一场
- [ ] SR-4 锚点平滑滚动：公开页点顶部场次锚点芯片，平滑滚动到对应成绩卡，卡片标题不被吸顶页头遮住
- [ ] SR-5 顶栏横滑导航：窄屏页头导航可横向滑动，且不与页面上下滚动冲突

### 2.6 大屏页（入口：`/screen`；iPad Safari，无 iPad 时用 iPhone 横屏近似并注明）
- [ ] SC-1 自动轮播：有进行中场次与已发布成绩时每 8 秒轮换一节；成绩公告内多场次轮换显示进度 N/M
- [ ] SC-2 横竖屏旋转：来回旋转后表格无溢出、vw 字号自适应、轮播不中断不跳拍
- [ ] SC-3 自动锁屏影响：屏幕自动锁定再解锁回 `/screen`，轮播应继续且数据最新；若定时器被挂起，记录实际恢复耗时
- [ ] SC-4 长时间挂机：屏幕常亮挂 30 分钟以上无卡死、白屏

### 2.7 通用检查（每页执行：`/login`、`/judge`、`/staff`、`/public/results`、`/public/team-standings`、`/public/schedule`、`/manual`）
- [ ] GE-1 横滑：每页竖屏下左右晃动手机，无水平滚动条/整页左右晃动（表格卡内横向滚动除外）
- [ ] GE-2 双主题可读性：深浅两模式下正文、灰字、表格边框、红色强调均清晰，无深字配深底
- [ ] GE-3 边缘返回手势：屏幕左缘右滑返回，不误触页内元素（背号芯片、主题按钮等）
- [ ] GE-4 点按跟手：无 300ms 延迟感，无刺眼蓝色点按高亮色块
